# Terry SoRelle
Hi, I’m @tsorelle

I am a retired software developer. With a background in C++, C#, Delphi, Javascript, Typescript and the usual web technologies: HTML, CSS, PHP...

My ongoing project is Peanut, a plug and play library of extensions to CMS systems for Quaker meetings and organizations. The system is written in PHP and TypeScript using the KnockOut MVVM library. 

For documentation for Peanut and its related components see my [documentation repository](https://github.com/tsorelle/peanut-docs/blob/master/documentation/index.md)
